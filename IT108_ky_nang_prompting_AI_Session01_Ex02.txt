3. Hiện trường giả (Mã nguồn bị rò rỉ)
Mã nguồn bị rò rỉ:
def connect_database():
    db_password = 'rikkei_secret_password_2026'
    api_key = 'google_gemini_api_abc123'
    print('Đang kết nối...')
4. Yêu cầu bài làm chi tiết
Bước 1: Chỉ ra các thông tin nhạy cảm:
Hãy chỉ ra 2 biến số chứa thông tin cực kỳ nguy hiểm nếu bị người ngoài biết được trong hiện trường giả trên.
2 biến số: db_password và api_key
Bước 2: Làm sạch code và viết prompt an toàn:
1. Hãy sửa lại đoạn code trên bằng cách thay thế thông tin mật thành các biến tượng trưng (ví dụ: '[YOUR_DATABASE_PASSWORD]', '[YOUR_API_KEY]').
def connect_database():
    db_password = YOUR_DATABASE_PASSWORD
    api_key= YOUR_API_KEY
    print('Đang kết nối...')


2. Viết prompt gửi kèm đoạn code đã làm sạch này lên AI để nhờ tối ưu, đảm bảo không rò rỉ bất kỳ thông tin nào.
Tôi đã viết code Python dưới đây, bạn hãy giúp tôi tối ưu lại đoạn code phía dưới và coi có sai sót gì không, những dữ liệu về Password và API key đã ẩn đi rồi.
def connect_database():
    db_password = YOUR_DATABASE_PASSWORD
    api_key= YOUR_API_KEY
    print('Đang kết nối...')
